# Company values

**Build the house you want to live in.** Values are decision shortcuts.

## Workshop

1. Best decisions we made — what principle enabled them?
2. Worst decisions — what value was missing?
3. Behaviors we reward vs tolerate

## Good value traits

- Actionable (helps choose in conflict)
- Memorable (one sentence)
- Distinct (not generic "integrity")

## Team contributors (LICENSE)

- Check the repo `LICENSE` / `CONTRIBUTORS` for the current contributor list, then align norms with how you already work.

## Output

- 3–5 values with **behavior examples**
- Anti-patterns (what we don't do)
- Interview / review questions per value
