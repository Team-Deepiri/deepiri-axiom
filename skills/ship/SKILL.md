# Ship skill (Deepiri)

## Four questions

1. Ship in a weekend? If not — cut.
2. Makes lives slightly better? That is the bar.
3. Will someone pay (even $1)?
4. Fast honest feedback?

## Default MVP shape

- One job, one outcome
- Forms and lists (CRUD) over platforms
- Existing tools before custom code

## Deepiri-specific

- Prove integration with curl/scripts before polish
- Keep compose and cross-repo changes in the smallest PR
- Do not block ship on a full training loop unless that **is** the wedge

## Output

- Single sentence MVP definition
- Implementation path: manual | no-code | minimal code
- What merges this week
- How feedback is collected
