# Minimalist review

Apply to whatever the user presents (feature, hire, marketing, refactor).

## Lenses

1. **Community first** — serves real users or ego metrics?
2. **Manual before automate** — proven by hand?
3. **Build little** — weekend scope?
4. **Sell before scale** — paid customers?
5. **Time before money** — free outreach exhausted?
6. **Profitability** — default alive?
7. **Customer speed** — they pulling this?
