# Deepiri Ecosystem

Triggers: setup, sibling repos, device/GPU, model providers, linking clones.

## Commands
```bash
./install.sh
./install.sh detect --write
./install.sh link
./install.sh status
```

Prefer **detected local paths** from the manifest over guessing clone locations.
