# Grow sustainably

**Grow at customer speed.** Default alive > default dead.

## Decision filter

- Reversible vs irreversible (lease, hire, VC)
- Closer to profitability?
- Customers asking for this or founder guessing?

## Spend order

1. Time (outreach, content)
2. Tools that replace proven manual time
3. People only when process is on paper (**processize**)

## Deepiri infra

- Don't scale GPU/training spend before eval proves value (**deepiri-tombstone**)
- Compose complexity last (**deepiri-compose-dev**)

## Output

Recommendation: **do now / wait / never** with tradeoffs.
